# Moy P0.1 follow-ups — 2026-10-19

Build follow-up to section 10 of `moy_pkg_P0.md`. The two P0.1 changes are in
the check suite and shot rig; no city geometry was authored for this package.

## Changes

1. **Underside checks follow the walk body's visual.** For each sampled walk
   cell, the suite finds meshes owned by that cell's nearest
   `CollisionObject3D`, then requires an upward-facing surface at the cell's
   height. It looks for a downward-facing triangle at that same x/z point,
   within the deck thickness, and casts upward through that thickness with
   back-face hits enabled. Faces are cached per mesh during the check. This
   stops a nearby rail, ring link or gallery from standing in for the deck.
2. **Under-flight cameras use reachable cells.** The shot rig prepares the
   same 0.5 m walk grid and reach graph as `world_checks.gd`. For each tagged
   flight run, it finds a reachable lower walk cell below a deck face, tests
   the camera-to-underside ray, and uses the clearest candidate. If no
   candidate passes, it prints `WORLD_SHOT_SKIP` with the run id and reason
   instead of writing a blank frame. `--package=P0.1` reads P0's ten named
   places and the standard viewpoints.
3. **Pulled plan bake.** The pull changed the plan's climber panel count from
   72 to 71. The static Moy packs were regenerated, and
   `tools/check_moy_bake.py` now expects the plan's current count.
