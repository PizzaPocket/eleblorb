2026-10-18. P0 implementation pass. **Not accepted as complete.** This diagnostic records the first Moy run and the gaps against `docs/architecture/moy_pkg_P0.md`.

## Moy run

Command: `Godot --headless --rendering-method gl_compatibility --rendering-driver opengl3 --path . tools/world_checks.tscn -- --kingdom=moy --date=2026-10-18`.

The scene streamed 190 packs and 4,004 collision bodies before the checks finished. The run took about 40 seconds end to end; the check timings total about 4.6 seconds. It exited non-zero because 49 findings were marked blocking. Full records and the first 20 findings per check are in [moy-2026-10-18.json](checks/moy-2026-10-18.json) and [moy-2026-10-18.md](checks/moy-2026-10-18.md).

## Seeded fixtures

Not run. The nine fixtures (overlap, buried, water, reach, trap, headroom, underside, solid, guard) were not built. The current prototype does not meet the brief's requirement that each fixture demonstrate a detected fault.

## Screenshot set

`tools/world_shots.tscn` and `tools/world_shots.gd` rendered four fixed views at 1280 × 720 using Godot 4.7.1 / Metal. The set contains overview, skyline, Civic Plaza street-level, and a view from under the high line; each has noon and dusk lighting. Files are in [`docs/diagnostics/images/2026-10-18-P0/`](images/2026-10-18-P0/). The overview and street frames were visually inspected. They render, although the overview is low contrast from the desert haze. The rig currently hard-codes these views; it does not yet read the model's `PLACES` table or take package-specific view ids, and the street/under-flight standard set is incomplete for packages with multiple districts or flights.

## Deviations and next work

The command-line scene, check ids, per-check timings, JSON/Markdown report, Moy loading wait and non-zero-on-blocking exit are present. The checking algorithms currently use transformed bounding boxes and a few center-point probes. They do not yet implement the brief's static-collider walk grid, 0.25 m rasterization, character-clearance flood fill, transport links, inside-region test, mesh winding/visibility checks, or full-outline edge guards. The `CollisionPolicy`/water/reach/ways-out tags also need builder coverage.

The brief's acceptance conditions remain open: replace the broad-phase proxies with the specified walk-surface algorithms, seed and run all nine fixtures, add builder metadata, make the screenshot rig read model places and package view ids, capture the complete package-specific set, then rerun Moy and record a meaningful finding baseline. No Moy geometry was changed to suppress this prototype's findings.
