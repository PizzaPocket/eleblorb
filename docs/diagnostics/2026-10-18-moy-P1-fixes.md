# Moy P1 fixes diagnostic

Date: 2026-10-18
Scope: section 4 fixes to prototype pass 4. No web export, commit, or push.

## Fixes

1. Split each Crossing head beam at the helix drums. Each Spine and Meridian
   beam now has an east/west or north/south piece from the tower ring-girder
   edge to 7.4 m from the Crossing centreline; the span between the drums is
   empty.
2. City Hall galleries now use their authored A, B, or AB band extents. G37
   and G43 occupy band B; L37o, L37i, and L43 span both bands and their gap.
   Deck tops are at each gallery's authored `y`.
3. Added a runtime validator query across each helix's annular rider band
   (r=1.4–4.0 m, tread level through 2.6 m above) and rejects colliders other
   than `CrossingHand_*` sections.
4. Added a runtime validator query for each authored tower `ways_out`, using
   its 2.4 m width and 2.8 m clear height through and beyond the drum.
5. Deleted `shaders/moy_pond_water.gdshader` and its `.uid`; no source
   references remain.

## Baseline evidence for the helix-band check

The pre-fix geometry fails the new band check by direct extent evaluation:
each 26 m beam occupied the full -13 m to +13 m span and crossed the annular
helix volume (r=1.4–4.0) at both drums. The prior world-check report
`docs/diagnostics/checks/moy-2026-10-18.json` also records those beams at
z=±13 and world x=-573/-547, confirming the previous long spans. This is an
extent-based pre-fix failure, not a replay of the new runtime query. Its
post-fix hit count remains unconfirmed because the full runtime validator
crashes before emitting its summary.
