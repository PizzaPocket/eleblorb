## Roles and handoff

- Sol planning: read roadmap and the relevant package only, refine the accepted
  design/model, write one current brief and a short implementation handoff.
  Mark whether it is proposed, design accepted, build-ready or implemented.
- Luna construction: build that handoff using shared working systems and fast
  local previews. Keep substantial collision and intentional circulation sound.
  Bake coherent batches/final integration, run required focused checks, provide
  a concise diagnostic and useful actual images, then stop for review.
- Sol review: inspect one stable submission at the practical Ohio/Snowhio bar.
  Report concrete gameplay/visual blockers separately from minor polish. No
  exhaustive fit ledger, universal reachability or open-ended review/fix loop.
  Local saved-pack physics, GPU views and streamed gameplay prove different
  things; report each honestly. A local review does not require a remote push.

## One writer for shared data and integration

While the current builder works, another planning chat may write separate
briefs and design notes. It must not edit city_layout.py, shared kit authoring,
CityPlan, runtime scripts, shared model scene/data or generated bake files at
the same time. Read-only source inspection is fine. Queue proposed shared-data
changes until the builder stops, then integrate once and regenerate CityPlan
from authoring. Do not hand-edit the generated plan or fake bake source hashes.
Serialize Godot validation and Git commit/pull/push operations too.

Use the existing implementation checkout. Main currently does not contain all
local P3–P9 work; a fresh clone/worktree is not equivalent. Preserve inherited
source, packs and diagnostics. Before a major integration checkpoint stable
work; after a coherent milestone, deliberately reconcile and publish verified
source/evidence with the human owner's identity/hooks. Do not wholesale-stage
unrelated work, reset/stash it for convenience or replace it with older packs.
No deprecated build/web export. Avoid repeated recovery archives or city-wide
bakes during ordinary small edits.
